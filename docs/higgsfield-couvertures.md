## Regénérer une couverture

```bash
higgsfield generate create nano_banana_pro --aspect_ratio 16:9 --resolution 2k --wait --json \
  --prompt "<prompt de style> <sujet>"
```

Puis conversion : PIL, recadrage 16:9, 1600x900, WebP qualité 82.
